# Irodori TTS Core ML 0.2.0

軽量INT8モデルを追加しました。約2.99 GBの現行版と、約1.96 GBの軽量版を同じSDKで利用できます。既存モデルと合成APIは引き続き使用できます。

- 軽量INT8版はテキストエンコーダーの重みをINT8で保存し、FP32の計算・入出力を維持します。iOS 18 / macOS 15以降が必要です。
- iPhone / Macサンプルにモデルのダウンロード選択と保存済みモデルの切り替えを追加しました。登録音声・話し方の指示・AudioSeal透かしは両版で使用できます。
- CLIに `download --variant standard|light-int8` と `info --models DIR` を追加しました。
- 量子化・数値検証・音声比較のツールと、日本語・英語の測定ドキュメントを追加しました。

[モデル取得](../HUGGINGFACE.md) · [音質と速度の測定](../QUALITY.md) · [English measurements](../QUALITY.en.md) · [サンプル操作](../SAMPLES.md)

ソースは `irodori-tts-coreml-source-0.2.0.zip`、モデルはHugging Faceで別配布です。初回のCore MLコンパイル時間・キャッシュ容量は別途必要です。
