# Irodori TTS Core ML v0.1.0

Irodori TTS v4.1 Small MFをiPhone / Apple Silicon Macで使うSwift SDKです。日本語の音声合成、参照音声による声の指定、テキストによるVoice Designに対応します。

## 配布物

- **irodori-tts-coreml-source-0.1.0.zip**: Swift SDK、iPhone / Macサンプル、Mac CLI、変換の参考コード、ドキュメントとライセンス。
- **irodori-tts-coreml-source-0.1.0.zip.sha256**: ソースZIPの照合用チェックサム。
- **[Core MLモデル一式](https://huggingface.co/AILogDev/Irodori-TTS-v4.1-Small-MF-CoreML)**: 約2.99 GB。15個のCore MLパッケージ、tokenizer、config、manifestと部品別ライセンス。SDKには内蔵していません。

## 始め方

SDKをアプリへ追加する場合は、Xcodeの **File → Add Package Dependencies…** に `https://github.com/Corvelis/irodori-tts-coreml.git` を入力し、**Exact Version 0.1.0** と **IrodoriTTS** productを選びます。[SDK導入ガイド](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/docs/GETTING_STARTED.md)を参照してください。

サンプルはソースZIPを展開して `Examples/IrodoriSamples.xcodeproj` を開きます。Macは `IrodoriMac`、iPhoneは `IrodoriiOS` schemeを選び、自分のSigning TeamとBundle Identifierを設定して実行します。

モデルはサンプルの「URLからダウンロード」またはMac CLIで取得できます。次のURLは、この版に対応するモデルcommitへ固定されています。

```text
https://huggingface.co/AILogDev/Irodori-TTS-v4.1-Small-MF-CoreML/resolve/b02a670f0cb41c382844672fa8f0f03b3b9b8082/manifest.json
```

manifestのSHA-256: `f98e77d857c20e977358ec9c9d513721b37e1af0d7e12359c05de26c90ae7186`

[モデル取得と配置](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/docs/HUGGINGFACE.md)、[サンプル操作](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/docs/SAMPLES.md)、[Mac CLI](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/docs/CLI.md)に詳しい手順があります。

## 主な機能

- 48 kHz、モノラル、PCM16 WAVの生成。
- 再生PCM・WAVへのAudioSeal透かし付与と、識別値の読み戻し。[日本語](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/docs/WATERMARK.md) / [English](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/docs/WATERMARK.en.md)。
- 参照音声なしの生成、録音・音声ファイルの取り込み、参照特徴の再利用と削除。
- 日本語のVoice Design指示。
- サンプルでの全文生成・再生・一時停止・再開・停止・WAV保存・RTF表示。
- SDKでの任意の文分割、PCMチャンク通知とキャンセル。
- CLIでのモデル検証、反復生成、性能測定。

## 要件と制約

iOS 17以降 / macOS 14以降が対象です。開発にはApple Silicon MacとXcodeを使用します。音声合成の実行にPythonやONNX Runtimeは不要です。

モデル原本約2.99 GBに加え、アプリ内コピーとCore MLコンパイルキャッシュを保存する容量が必要です。初回はコンパイルとロードに時間がかかります。

GUIサンプルは全文を一度に合成し、完成WAVを再生します。本文256トークン（BOSを含む）・潜在系列768フレームの上限を超える場合は、文章を短くしてください。速度・使用メモリ・声質は入力や実行環境によって変わります。変換コードは参考実装で、一般利用には配布済みモデルを推奨します。
