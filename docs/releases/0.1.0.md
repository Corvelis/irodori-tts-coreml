# Irodori TTS Core ML v0.1.0

Irodori TTS v4.1 Small MFをiPhone / Apple Silicon Macで使うSwift SDKの初版です。iPhone/Mac共通のSwiftUIサンプル、Mac CLI、モデル変換の参考コード、利用手順と部品別ライセンスを含みます。

## 配布物

- `irodori-tts-coreml-source-0.1.0.zip`: SDK・サンプル・CLI・変換コード・ドキュメント。モデルや音声は含みません。
- `irodori-tts-coreml-source-0.1.0.zip.sha256`: ソースZIPのSHA-256。
- [Core MLモデル一式](https://huggingface.co/AILogDev/Irodori-TTS-v4.1-Small-MF-CoreML): 約2.90 GB、13個のCore MLパッケージとtokenizer、manifest、ライセンス。

公開範囲は、作成時点ではGitHub・Hugging FaceともPrivateです。一般公開と公開後の認証なし取得確認は別工程として残しています。Privateの間は各サービスの認証が必要です。

## SDKとサンプル

Xcodeの **File → Add Package Dependencies…** に `https://github.com/Corvelis/irodori-tts-coreml.git` を入力し、Exact Version **0.1.0** を選びます。アプリtargetに **IrodoriTTS** productを追加してください。

サンプルはソースZIPを展開するか、次のようにタグから取得します。

```sh
git clone --branch v0.1.0 --depth 1 https://github.com/Corvelis/irodori-tts-coreml.git
cd irodori-tts-coreml
open Examples/IrodoriSamples.xcodeproj
```

Macは `IrodoriMac`、iPhoneは `IrodoriiOS` schemeを選び、自分のSigning TeamとBundle Identifierを設定します。サンプルは参照音声の録音・取り込み・削除、Voice Designの指示、全文生成後の再生・一時停止・再開・WAV保存に対応します。

## 固定モデル取得URL

モデルのbundleVersionとSDK版は **0.1.0** です。モデルcommit:

`3db2ed296c75196a34f4f40f05dc9f552f79d115`

[manifest.json](https://huggingface.co/AILogDev/Irodori-TTS-v4.1-Small-MF-CoreML/resolve/3db2ed296c75196a34f4f40f05dc9f552f79d115/manifest.json) のSHA-256:

`9ec645e4396a8ded1d626e528fdd77b3b8ac1cfb4f4d2f8355fc1bfaae017ca6`

SDKのダウンロード機能は認証なしの公開URL向けです。モデルがPrivateの間はMac等で認証して取得したフォルダを使ってください。一般公開後は、次の固定URLから未作成の保存先へ取得できます。

```sh
swift build -c release
.build/release/irodori download \
  --manifest 'https://huggingface.co/AILogDev/Irodori-TTS-v4.1-Small-MF-CoreML/resolve/3db2ed296c75196a34f4f40f05dc9f552f79d115/manifest.json' \
  --destination ../Irodori-TTS-v4.1-Small-MF-CoreML
.build/release/irodori verify --models ../Irodori-TTS-v4.1-Small-MF-CoreML
.build/release/irodori synthesize \
  --models ../Irodori-TTS-v4.1-Small-MF-CoreML \
  --text 'こんにちは。今日はいい天気ですね。' \
  --output /tmp/irodori-output.wav
afplay /tmp/irodori-output.wav
```

## 確認範囲

モデル本体50ファイルと推論コード12ファイルは、実機試験・試聴済みの構成から変更していません。モデルの固定commitにある全63ファイルはサイズ・SHA-256を確認しています。変更のないモデルファイルは、以前に全ファイルを新しく取得・検証したキャッシュを再利用しています。

Swiftの通常テストは8件成功・実モデルが必要な3件はスキップ、配布ツールのテストは6件成功です。iPhone 17 ProとApple M2 Macでのサンプル操作・音声の確認記録は[検証記録](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/docs/VALIDATION.md)にあります。一般公開後の認証なし取得・生成・再生確認は別工程です。

## 要件とライセンス

ビルド対象はiOS 17以降 / macOS 14以降です。全OS・全端末での音質や速度を保証するものではありません。実行時にはAppleのフレームワークを使い、PythonやONNX Runtimeは不要です。変換コードは個別のモデル生成に使用した参考実装で、新しい環境での取得から全再変換までの一括手順は未検証です。

SDKの新規部分はApache-2.0、モデルと派生部分はMIT/Apache-2.0の部品別条件を保持します。[部品別ライセンス](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/THIRD_PARTY_NOTICES.md)と上流の使用条件に従ってください。使用許可のある声を使い、合成音声を本人の実際の発話として偽らないでください。この変換には透かし付与の保証はありません。

詳しい操作は[SDK導入](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/docs/GETTING_STARTED.md)、[サンプル操作](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/docs/SAMPLES.md)、[音声登録](https://github.com/Corvelis/irodori-tts-coreml/blob/v0.1.0/docs/VOICE_REGISTRATION.md)を参照してください。
