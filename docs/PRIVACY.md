# Irodori Core MLサンプルのプライバシー

[English](PRIVACY.en.md)

この説明は、リポジトリで提供するiPhone / Macサンプルアプリの標準構成に適用します。

## 文章と音声

入力した文章、話し方の指示、録音、取り込んだ参照音声は端末内で処理します。音声合成・Voice Cloningのために外部サーバーへ送信しません。マイクは利用者が録音を開始し、OSのアクセス許可を与えた場合だけ使用します。

アプリは選択モデル、話し方の指示、参照音声の選択を端末内に保存します。参照音声のコピーと声の特徴キャッシュも端末内へ保存し、「登録音声とキャッシュを削除」で削除できます。元の外部音声ファイルは削除しません。

生成した音声はアプリ内へWAVとして保存します。次の生成が成功するとアプリ内の出力WAVを置き換えます。生成音声には、AI音声の識別を補助するAudioSealの透かしを付与します。透かしは音声内の信号で、外部への通信や個人情報の送信は行いません。

## 通信

モデルを取得するときにHugging Faceへ接続します。通常の接続として、IPアドレスや要求したファイルなどの情報が配布先サーバーへ届きます。文章や参照音声はその要求に含めません。配布先の情報の扱いは[Hugging Faceのプライバシーポリシー](https://huggingface.co/privacy)を参照してください。

独自manifest URLを指定した場合は、その配布先へ接続します。モデル取得後の音声合成にネットワーク通信は必要ありません。外部リンクは、利用者が開いた場合にブラウザー等へ渡します。

## 保存・共有・削除

WAVの保存先や共有先はOSの画面から利用者自身が選びます。外部へ共有したデータには、その保存先・サービスの設定やポリシーが適用されます。

不要な保存済みモデルは「モデルを管理」で削除できます。中断した取得データは「取得データを削除」で消せます。アプリの削除ではアプリ内データが削除されますが、外部へ保存・共有したファイルは残ります。端末・OSのバックアップ設定によっては録音や設定等がバックアップされます。再取得できるアプリ内モデルフォルダはバックアップ対象から外しています。

## 解析と問い合わせ

サンプルアプリ独自の広告、追跡、アクセス解析SDKはありません。TestFlightを通じて配布した場合のクラッシュ情報や利用者が送るテストフィードバックは、AppleのTestFlightの仕組みで扱われます。[Appleの説明](https://developer.apple.com/testflight/)を参照してください。

サンプルに関する問い合わせは[GitHub Issues](https://github.com/Corvelis/irodori-tts-coreml/issues)へ送れます。公開の問い合わせに、個人の録音や機密の文章を添付する必要はありません。
